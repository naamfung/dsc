# 代碼審計技能 (Code Audit Skill)

當用戶要求審計、審查或檢查代碼時，使用此技能執行全面的代碼審計。

## 審計維度

### 1. 安全性 (Security)
- **注入漏洞**：SQL 注入、命令注入、LDAP 注入、XML 外部實體 (XXE) 攻擊。
- **跨站腳本 (XSS)**：反射型、存儲型、DOM 型 XSS。
- **認證與授權**：弱密碼策略、會話固定、越權訪問 (水平/垂直)、JWT 簽名泄露。
- **數據泄露**：硬編碼憑證（API Keys、密碼、私鑰）、敏感數據未加密存儲或傳輸。
- **依賴項漏洞**：使用已知存在漏洞的第三方庫 (CVE 檢查)。
- **文件操作**：路徑遍歷 (Path Traversal)、不安全的文件上傳。

### 2. 邏輯錯誤 (Logic Errors)
- **邊界條件**：數組越界、除數為零、空指針解引用。
- **狀態管理**：競態條件 (Race Conditions)、死鎖、狀態不一致。
- **業務邏輯**：支付金額被篡改、權限校驗缺失、業務流程繞過。

### 3. 性能與資源 (Performance & Resources)
- **資源泄露**：數據庫連接未關閉、文件句柄未釋放、內存泄露。
- **低效查詢**：N+1 查詢問題、缺少索引、複雜 JOIN。
- **阻塞操作**：在關鍵路徑中使用同步 I/O 或阻塞調用。

### 4. 代碼規範與可讀性 (Code Quality)
- **命名規範**：變量、函數、類命名不清晰或不一致。
- **代碼重複**：存在可提取的公共邏輯或工具函數。
- **複雜度**：函數過長、嵌套過深、循環複雜度高。
- **註釋與文檔**：關鍵邏輯缺少註釋或文檔不完整。

## 審計輸出格式

對於每個發現的問題，請按以下格式輸出：

```
### [問題級別] 問題標題
- **位置**：文件路徑及行號（如果可識別）
- **描述**：詳細說明漏洞或問題的性質
- **風險評估**：高/中/低
- **修復建議**：具體的代碼修改建議或最佳實踐
```

**問題級別分類**：
- `🔴 高風險 (Critical)`：安全漏洞、數據丟失風險、系統崩潰。
- `🟡 中風險 (Warning)`：性能問題、潛在邏輯錯誤、規範違反。
- `🟢 低風險 (Info)`：代碼風格、可讀性優化建議。

## 審計流程

1. **上下文理解**：閱讀代碼，理解業務邏輯和數據流向。
2. **逐層檢查**：按照上述審計維度逐一檢查代碼。
3. **問題歸類**：將發現的問題按級別和維度分類。
4. **生成報告**：按照指定格式輸出審計報告，優先處理高風險問題。
5. **修復驗證**：在提供修復建議後，可協助驗證修復後的代碼是否解決了問題。
