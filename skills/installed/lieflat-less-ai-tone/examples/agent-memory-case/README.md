这个文件夹把同一篇文章的改前检测、建议、改稿、左右对照和复测放在一起，供阅读或作为 skill 工作流示例。

| 阶段 | 产出 | 用途 |
|---|---|---|
| 原始输入 | [原稿](00-原稿.md) | 核对事实和文字起点。 |

| 阶段三：复测 | [复测结论](04-复测结论.md) | 核对剩余命中、误报和内容守恒。 |
